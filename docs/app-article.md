# VCDView v1.0 发布：开箱即用的轻量 VCD 波形查看器

> 面向硬件工程师 / FPGA 开发者 · 应用向

---

## 一个很现实的场景

仿真完一个模块，SimVision / Vivado 启动要十几秒，GTKWave 打开 3MB 的 VCD 要转 5 秒的圈。你只是想快速确认信号时序对不对。

**VCDView 的目标就是：双击打开、1 秒出波形、用完即走。**

## VCDView 是什么

一款 Windows 桌面波形查看器，支持 VCD（IEEE 1364 Value Change Dump）格式，兼容主流仿真器导出的仿真波形。单文件免安装，拷贝即用。

## 核心功能

- **秒开大文件**：3.68MB / 59.5 万行 / 2857 信号的 VCD，打开到可操作约 1 秒（GTKWave 同类文件需要数秒）
- **信号层次树**：按 scope 层级组织，支持展开/折叠，与 Vivado/Quartus 一致的浏览习惯
- **波形视图**：Canvas 高效渲染，支持缩放、平移、按时间窗定位
- **按需查询**：波形数据按可见时间窗增量加载，千万行级别文件也不卡主线程
- **中文界面**：全中文交互，硬件工程师零学习成本
- **单文件免依赖**：基于 C++ 静态链接 + WebView2，无 Node、无服务进程、无安装流程

## 一分钟上手

1. 从发布页下载 `VCDView.exe`
2. 双击运行，`打开文件` 选择你的 `.vcd` 文件
3. 左侧树展开 scope，勾选信号
4. 波形区即出波形，滚轮缩放、拖拽平移

## 技术底子（为什么敢说"快"）

- 复用 GTKWave 久经考验的 C 解析内核，而非从零解析 VCD
- C++17 后端 + WebView2 渲染 + React 前端（TauriCPP 框架）
- 深度性能调优：移除解析热路径的日志 I/O 后，解析速度提升 8 倍
- 波形渲染走 Canvas 2D + 按需抽稀，不做 DOM 逐点
